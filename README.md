# Cultist Simulator VSCode Extension 2.0

Simplifies Cultist Simulator modding by providing an interactive editor with panels, also comes with a primitive debugger.
Simplified Chinese version

## 为什么要发布这个版本？

原始版本的发布者——tiinusen太过懒惰，在2022年后放弃了对插件的维护，以至于大量在那之后添加的原版字段未被收录，且对于现代CSmod的基石mod，The Roost的扩展字段也完全不支持，在当前的json逻辑编写时已经极为不便。因此我将这些字段补充到自动补全插件中——基本上保持和灰机Wiki上同步。
